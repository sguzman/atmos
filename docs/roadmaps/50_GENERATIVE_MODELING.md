# Generative Declarative Modeling

Focus: expressive characters, props, and environments compiled from semantic descriptions.

## Milestone M1: Declarative puppet characters

- [ ] Create a first declarative character schema.
- [ ] Compile a simple segmented puppet from semantic parameters.
- [ ] Generate a corresponding simple skeleton or control structure.
- [ ] Preserve a deliberately stylized constructive aesthetic if it helps velocity.

## Milestone M2: Expressive body parameters

- [ ] Encode body proportions.
- [ ] Encode head and face proportions.
- [ ] Encode eye, brow, and mouth landmarks.
- [ ] Encode rest posture or gesture defaults.
- [ ] Connect anatomy parameters to expressive behavior.

## Milestone M3: Procedural asset language

- [ ] Support building forms from superquadrics, sweeps, extrusions, revolve operations, or CSG.
- [ ] Keep TOML or another declarative source as the semantic ground truth.
- [ ] Compile to ordinary meshes usable by Bevy at runtime.

## Milestone M4: Emotional creature expressiveness

- [ ] Characters can expose expressive brow/eye/mouth controls.
- [ ] Body form and rig support readable emotional performance.
- [ ] Stylized creatures remain simulation-ready, not only render-ready.

## Milestone M5: World generation expansion

- [ ] Extend declarative modeling to props.
- [ ] Extend declarative modeling to buildings.
- [ ] Extend declarative modeling to vegetation.
- [ ] Create style grammars that can scale into a coherent village.
