# Atmos Roadmaps

This folder is the working milestone package for Atmos.

These files are meant to be edited continuously as implementation advances.
When work lands, the relevant checkbox should be updated in the matching file.

## How to use this folder

- `00_PROJECT_CHARTER.md` defines the north star.
- `01_ITERATION_PROTOCOL.md` defines how implementation work should proceed.
- `10_*` through `60_*` are capability tracks.
- `80_INTEGRATION_MILESTONES.md` is the recommended build order.

## Status conventions

- `[ ]` not started
- `[~]` in progress
- `[x]` completed

## Current expectation

Atmos should evolve as one convergent architecture rather than separate projects for:

- autonomous agents
- agentic systems
- emotional systems
- expressive animation
- generative declarative 3D modeling
- village-life simulation

Every major change should eventually connect back to the full causal chain:

`world systems -> perception -> beliefs/memory -> needs/emotions/relationships -> decision -> action -> motor intent -> animation/expression -> visible behavior -> social/systemic reaction`
