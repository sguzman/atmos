# Emotional Systems

Focus: emotion as a causal simulation layer that affects behavior and expression.

## Milestone E1: Emotional state foundations

- [ ] Define a compact emotional-state representation.
- [ ] Separate appraisal, emotional state, expression, and behavior.
- [ ] Add emotional variables such as arousal, valence, confidence, tension, and social stance.
- [ ] Allow emotions to bias utility and action preferences.

## Milestone E2: Appraisal model

- [ ] Events can be appraised relative to needs, goals, threats, and relationships.
- [ ] Positive and negative outcomes alter emotional state.
- [ ] Social events can alter emotional state.
- [ ] Emotional changes are inspectable in debugging.

## Milestone E3: Personality mediation

- [ ] Personality traits modulate expression intensity.
- [ ] Personality traits modulate behavioral response.
- [ ] The same emotion can yield flee/freeze/confront/hide/seek-support variants.

## Milestone E4: Social inference without telepathy

- [ ] Agents do not directly read another agent's emotional state.
- [ ] Agents infer likely emotional state from visible behavior.
- [ ] Agents can be wrong about others.
- [ ] Misunderstanding can affect relationships and decisions.

## Milestone E5: Emotional consequences

- [ ] Emotions can alter speed, posture, gaze, and gesture.
- [ ] Emotions can alter compliance, conflict, avoidance, and cooperation.
- [ ] Emotional history contributes to relationship change.
