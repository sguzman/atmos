# Village Life

Focus: scaling from one agent loop to a small legible society.

## Milestone V1: One household

- [ ] Two to five agents can co-exist in one shared space.
- [ ] Hunger, thirst, and fatigue all matter.
- [ ] Food, water, beds, and storage exist as world resources.
- [ ] At least one simple production chain exists.

## Milestone V2: Social and logistical friction

- [ ] Agents can wait for resources.
- [ ] Resource contention can create frustration or delay.
- [ ] Delays can affect schedules or priorities.
- [ ] Relationship changes can emerge from small frictions.

## Milestone V3: Work and routine

- [ ] Agents have a home context.
- [ ] Agents have a work context or role.
- [ ] Agents can transition between maintenance, labor, and leisure.
- [ ] Day-scale simulation can run for multiple in-game days.

## Milestone V4: Tiny village

- [ ] Scale to roughly 10-30 agents.
- [ ] Add multiple households.
- [ ] Add professions and public spaces.
- [ ] Add ownership, exchange, or trade.
- [ ] Add reputation, cooperation, and conflict.

## Milestone V5: Legibility before scale

- [ ] Prefer understandable village behavior over large NPC counts.
- [ ] Maintain debugging and inspection support as the social graph grows.
- [ ] Validate that observed behavior is explainable through systems, not scripts.
