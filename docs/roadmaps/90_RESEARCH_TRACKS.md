# Research Tracks

These are important, but they should not be allowed to hijack the main vertical-slice trajectory.

- [ ] Explore ordinary-camera motion capture inputs.
- [ ] Reconstruct canonical skeleton motion offline.
- [ ] Clean up with smoothing, contact correction, and retargeting.
- [ ] Import resulting clips into Atmos as source material.
- [ ] Preserve runtime semantic animation control above imported clips.

- [ ] Explore TOML-to-geometry graph compilation.

- [ ] Keep this track from blocking simpler puppet-style progress.
